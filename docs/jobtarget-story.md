# JobTarget experience and animation

The feature follows SwipeBuilder. Career details and outcomes come from the portfolio’s existing `dist/data/profile.json`; the ATS-to-job-board system story comes from the user’s description. The sample job titles, generic ATS sources, board categories, and routing signals illustrate the concept. No proprietary matching algorithm, live delivery status, or distribution performance claim is asserted.

The original React/Remotion composition is drawn with HTML and SVG, using paper windows, hand-drawn route styling, moving job tickets, and a routing desk. No existing project illustration is reused. Desktop flows left to right, while mobile flows top to bottom. Manrope carries system labels and experience copy; Caveat supplies section titles and short illustrated notes.

The four 180-frame chapters cover pulling jobs, preparing records, matching destinations, and delivery. Controls support play/pause, replay, keyboard timeline seeking, direct chapter selection, and scroll scrubbing. A text alternative replaces the player when reduced motion is preferred or reading mode is chosen. The README illustration is a screenshot of the finished composition.
