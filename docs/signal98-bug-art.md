# Signal98: the bug's journey

Original transparent assets generated with the built-in image generation tool:

- `dist/assets/signal98-bug-v1.png`: one expressive graphite beetle, facing right.
- `dist/assets/signal98-jev-machine-v1.png`: an open inspection portal, with the JEV / TypeSafe AI label rendered in code.

`src/signal98-bug-film.jsx` animates these assets through a continuous 24-second timeline. The bug arrives with captured context, moves into the conceptual JEV scanner, receives category/severity/user-impact judgments, and travels to Ghost for investigation. Application rules set priority; JEV is not depicted generating fixes. The small magnifying-glass Ghost and paths are original SVG elements. All motion is derived from the frame, so scrolling backward reverses the same sequence.

The old workbench backdrop is retained as an earlier asset but is no longer used by the Signal98 film. The new scene has its own character, machine, layout, and choreography.

## Generation prompts

### Bug

Use case: illustration-story. Create a single isolated character asset for a whimsical engineering portfolio animation. A charming small software bug depicted as a round beetle, three-quarter side view facing right, six little articulated legs, two curved antennae, expressive curious eyes and small folded wings. Fine graphite pencil, detailed monochrome crosshatching, light charcoal gray shell with white eyes, warm handmade editorial illustration, adorable but not babyish. Entire bug visible with generous clear margin. Exactly ONE beetle, no text, no labels, no duplicates, no floor, no scenery, no shadow outside the body. Genuinely transparent background. Square 1024x1024. Strong distinct silhouette recognizable at small size; head at right, body at left. It will be animated crawling and floating into an error-assessment machine.

### Assessment machine

Use case: illustration-story. Create one isolated original imaginary desktop scanner machine for a playful software-error assessment animation. A freestanding open circular inspection portal on a small sturdy control-console base, symmetrical front view with slight dimensional pencil shading. Large completely EMPTY circular opening in upper two thirds, narrow rounded metal rim with little glass bulbs, short supports, small analog meter and three knobs on bottom console. The opening is transparent so a bug character can travel through it. Fine graphite pencil and monochrome crosshatching, off-white metal with gray details, friendly ingenious scientific instrument, handcrafted editorial illustration. ONE machine fully inside image with generous margins, no characters, no bug, no screens with words, absolutely no text or logos, no extra props or floor. Genuinely transparent background, including the center opening. Square 1024x1024. This is a conceptual classification instrument, not a real brand logo.
